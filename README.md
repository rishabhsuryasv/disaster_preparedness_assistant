# Disaster Preparedness Assistant (India: Floods & Cyclones)

Hackathon problem #11. Two versions of the app:

| Folder | What it is | How to run |
|---|---|---|
| `disaster-prep-assistant/` | Single-file offline app with live NDMA SACHET alerts via a tiny Python helper | Double-click `Start-App.bat` (or open `DisasterPrepAssistant.html`) |
| `disaster-prep-pwa/` | Installable PWA version with tests and Netlify deploy notes | See `disaster-prep-pwa/DEPLOY.md` |

Features: verified emergency contacts, Before/During/After checklists, step-by-step safety guides, flood/cyclone modes, 4 languages, alert map, always-visible SOS (112).
