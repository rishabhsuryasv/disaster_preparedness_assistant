# Disaster Preparedness Assistant (India: Floods & Cyclones)

Double-click **Start-App.bat**. It opens the app with LIVE alerts from NDMA SACHET (needs Python, already on most PCs).
No Python? Double-click **DisasterPrepAssistant.html** - it still works offline, using a saved copy of the official alert feed.

Data you enter is saved in your browser. `data/` holds the content/translations; `src/build.js` rebuilds the HTML and refreshes the saved alert snapshot.
